## MODULE: capture_callback.py

  [HOW IT WORKS]
  This is an example of an injected callback capture server for Schwabdev's authentication process (no copy/pasting URLs during auth). You must have a free port in your callback URL such as `https://127.0.0.1:7777`. The browser will say that the connection is not secure (e.g. net::ERR_CERT_AUTHORITY_INVALID) because it is using a self-signed certificate, though this is fine because it is a local connection.
